# Glosario (lenguaje ubicuo)

| Término | Significado en Hotel Costa Azul |
|---|---|
| Huésped | Persona que reserva y se hospeda. Puede estar activo o inactivo y ser preferente. |
| Huésped preferente | Huésped al que el hotel reconoce con un beneficio cuando cumple las condiciones. |
| Categoría de habitación | Tipo de habitación del catálogo, con tarifa por noche y cupo. |
| Tarifa | Precio por noche de una categoría. |
| Cupo | Cantidad de habitaciones-noche que todavía se pueden comprometer en una categoría. |
| Habitación | Cuarto físico con número y estatus. |
| Estatus de habitación | Disponible, ocupada, pendiente de limpieza o fuera de servicio. |
| Disponible | Habitación limpia, lista y sin huésped. |
| Pendiente de limpieza | Habitación ya desocupada que Limpieza aún no libera. |
| Fuera de servicio | Habitación que no se puede asignar ni reservar. |
| Reservación | Compromiso del hotel con un huésped para una o más categorías. |
| Línea de reservación | Renglón con categoría, cantidad y tarifa acordada. |
| Solicitada | Reservación registrada que aún no se confirma. |
| Autorización | Visto bueno de Reservaciones para poder confirmar una reservación. |
| Confirmada | Reservación aceptada que ya descontó cupo. |
| Cancelada | Reservación que el huésped o Reservaciones dieron de baja antes del check-in. |
| No-show | Reservación confirmada a la que el huésped no llegó. |
| Garantía | Respaldo (tarjeta o depósito) que se valida en el check-in. |
| Check-in | Llegada formal: identidad verificada, garantía aprobada y entrega de habitación. |
| Estancia | Periodo en que el huésped ocupa la habitación. |
| Cuenta de estancia | Cargos y pagos de una estancia. |
| Cargo | Línea de la cuenta: hospedaje o consumo adicional, con el empleado que lo capturó. |
| Cambio de habitación | Reasignación durante la estancia, con registro de origen, destino, motivo y responsable. |
| Check-out | Salida: se paga el saldo, se cierra la cuenta y la habitación pasa a limpieza. |
| Beneficio preferente | Reconocimiento que se otorga al confirmar una reservación de un huésped preferente. |
| Specification | Regla de negocio pequeña que se evalúa sobre una reservación y se combina con Y, O y No. |
| Aggregate | Grupo de objetos que se guardan juntos y se modifican por su raíz. |
| Domain Event | Hecho del negocio ya ocurrido, por ejemplo HabitacionDisponible. |
| Unit of Work | Agrupa los cambios de un caso de uso: se guardan todos o ninguno. |
| Rol | Función de quien opera el sistema: Reservaciones, Recepción, Limpieza o Administración. |
| Tope de crédito (CAMBIO) | Máximo de $3,000 MXN de consumos pendientes por habitación; se supera con pago parcial o autorización de Administración. |
| Penalidad de cancelación (CAMBIO) | Cargo de una noche si se cancela una reservación confirmada con menos de 48 h de anticipación, salvo excepción autorizada. |
